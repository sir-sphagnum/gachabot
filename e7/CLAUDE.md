# E7 notes

E7's notes live in `e7/notes/`, one file per topic. Add to the matching file there rather than here.

- `notes/UI.md`: how each menu behaves (states, how to identify and switch them, quirks found while testing), one section per menu.

`python -m core.nav e7 goto <menu>` takes the game to any menu in `e7/templates/` reachable from the lobby (navigate skill).
