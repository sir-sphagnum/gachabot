# Reverse: 1999 notes

Reverse: 1999's notes live in `re1999/notes/`, one file per topic. Add to the matching file there rather than here.

- `notes/UI.md`: how each menu behaves (states, how to identify and switch them, quirks found while testing), one section per menu.
- `notes/routines.md`: named groups of routines (e.g. "daily routine") and what each runs.

`python -m core.nav re1999 goto <menu>` takes the game to any menu in `re1999/templates/` reachable from the lobby (navigate skill).
