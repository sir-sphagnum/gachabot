# Reverse: 1999 routines

Named groups of routines the user asks for by one name. Each routine is in `re1999/routines/` and registered in `re1999.routines.ROUTINES`.

## daily routine

`python -m re1999.bot start lobby claim_mail lobby_interact claim_wilderness fight_boss pneuma_analysis poussiere claim_dailies`. The claims cost nothing; fight_boss, pneuma_analysis and poussiere spend stamina (14, one Pneuma chance, 25 per run). `claim_dailies` runs last because the others count towards Daily Activeness.
