# Blue Archive notes

Blue Archive's notes live in `ba/notes/`, one file per topic. Add to the matching file there rather than here.

- `notes/UI.md`: how each menu behaves (states, how to identify and switch them, quirks found while testing), one section per menu.
- `notes/routines.md`: named groups of routines (e.g. "daily routine") and what each runs.

`python -m core.nav ba goto <menu>` takes the game to any menu in `ba/templates/` reachable from the lobby (navigate skill).
